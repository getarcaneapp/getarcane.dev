## Design principles

<CardGrid>
	<Card title="Small, focused modules" icon="puzzle">
		Each module has its own `go.mod` and its own release tags, so you only pull in the
		dependencies you use.
	</Card>
	<Card title="Adapter-driven" icon="setting">
		Services such as the updater and the build engine ship working Docker-backed defaults.
		The host application replaces only the parts it owns.
	</Card>
	<Card title="Safe by default" icon="approve-check">
		Filesystem writes are atomic and confined to a root, and inputs are validated
		before anything touches Docker.
	</Card>
	<Card title="Standard library first" icon="rocket">
		Small modules such as `sys/bytes` and `acfs/atomic` depend only on the standard library.
	</Card>
</CardGrid>
